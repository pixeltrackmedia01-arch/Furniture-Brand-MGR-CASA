## Care and usage

### Do

* Industry standard stationary to be used on white board markers
* Industry standard cleaning liquids to be used
* All accessories must be used for its specified use only
* Handle all Glass components with extreme care
* Use appropriate magnets for Magnetic boards
* All disassembly or alterations to be conducted by Featherlite technicians only

### Do not

* Drag sharp / metallic objects on the work surface
* Avoid sitting on the work surface, it is only for IT equipment
* Drag or move partitions, needs to be done by Featherlite technicians
* Use strong solvents like petrol/spirit/thinner for cleaning white marker board, laminates, fabrics and leather
* Spill any sort of liquid on partition walls
* Any sort of abuse to or on the furniture
